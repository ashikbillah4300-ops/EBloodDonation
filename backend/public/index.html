System & Synchronization Architecture

Direct integration between Admin Dashboard, PostgreSQL Database, and Android Client

Synchronization Flow

┌──────────────────────────────────────────────┐
│ PostgreSQL Database (Sequelize ORM) │
│ Tables: users, blood_requests, app_settings │
└──────────────────────┬───────────────────────┘
│
Node.js + Express API
│
┌──────────────┴──────────────┐
│ │
┌──────▼────────┐ ┌──────▼────────┐
│ Admin Panel │ │ Mobile App │
│ Web / Local │◄───────────►│ EBloodDonation│
└───────────────┘ └───────────────┘

1. Instant Config Updates: Changing the donation number or notices writes to app_settings. Mobile devices read this via /api/settings on resume or pull-to-refresh without rebuilding the APK.

2. Room + Cloud Dual-Layer: The Android app caches settings locally in Room so the app functions seamlessly even during momentary internet drops.

3. Protected Admin Endpoints: Admin APIs are secured by JWT token headers and strict rate-limiting.
